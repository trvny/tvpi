# GitHubowa Kraina

> Interaktywny atlas publicznych projektów `trvny` i `twojstar`.

Canonical page: https://trfny.com/teksty/githubowa-kraina/

## Map

- **Główne regiony:** Feedseek, Kanarek, WAM Bridge, LlmBench, Autka i TVPI.
- **Dzielnica Narzędziowa:** `twojstar/twojstar` jako wspólny warsztat dla Benchów, Weather, Feedboarda, Xiaomi ADB, pluginów i eksperymentów.
- **Drogi i podziemia:** `.ai` oraz `WiFi-Automatic` jako infrastruktura i utrzymywany fork.
- **Bramy:** profile GitHub `trvny` i `twojstar`.
